# Delegated MindGames Arena

MetaMask Smart Accounts Kit x 1Shot API hackathon submission.

Delegated MindGames Arena is a Telegram-playable multi-agent arena where humans grant bounded smart-account permissions, AI agents coordinate under hidden information, and performance-bond settlement is prepared through a 1Shot-style cross-chain flow.

## Scope note

The MVP uses live testnet transactions where available. 1Shot live Sepolia relayer support was not confirmed, so the repository frames the current flow as a 1Shot-ready adapter and trace-mode cross-chain settlement demonstration rather than a production mainnet bridge.
